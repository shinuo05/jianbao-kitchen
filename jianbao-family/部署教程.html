🥟 煎包今天做什么

把网站放到 GitHub Pages，把一家人的菜谱与图片放到 Supabase。配置完成后，手机、电脑打开同一个网址就能共享。

这份文件还没有连接你的云端账号。只上传 HTML 不会自动开启同步，需要依次完成下面步骤。

1 · 创建免费的 Supabase 项目

  1. 打开 Supabase 控制台，注册或登录，可使用 GitHub 登录。
  2. 创建 Free 组织及 New project，名称可填 jianbao-kitchen。选择适合家人的区域，设置并保存数据库密码（这个密码不要放进网站）。
  3. 等待项目准备完成。免费套餐目前为 500MB 数据库、1GB 文件存储，低活跃约一周可能暂停，需登录后台恢复。查看 当前免费额度。

2 · 初始化数据库与图片权限

  1. 打开项目左侧 SQL Editor → New query。
  2. 用记事本打开压缩包中的 setup.sql，复制全部内容，粘贴进 SQL Editor，点击 Run。
  3. 显示成功后，Table Editor 应出现 family_members 和 kitchen_state；Storage 中应有私有桶 kitchen-images。

请在新项目执行一次。脚本不会清除已有表；重复执行会报“已存在”，不要为此删除已有家庭数据。这个脚本已经配置成员权限，不要关闭 RLS，也不要把图片桶改为 Public。

3 · 创建你和家人的登录账号

  1. 在 Authentication → Users → Add user → Create new user 中，为自己创建邮箱和密码账号，启用 Auto Confirm（自动确认邮箱）。为家人分别创建账号。
  2. 在 Authentication 的 Sign In / Providers 设置中关闭 Allow new users to sign up。保留 Email / Password 登录。
  3. 复制每个用户的 UID。在 Table Editor → family_members → Insert row 中把 UID 填入 user_id，保存。每位家人一行，包括你自己。

只创建 Auth 账号还不够，必须加入 family_members 才能进入厨房。家人无需 Supabase 管理员账号，也不要把项目后台账号共享给他们。密码请通过你信任的方式单独告知家人；忘记密码可由管理员在后台管理该用户。

4 · 填写网站连接信息

在项目的 Connect 或 Settings → API Keys / Data API 页面找到 Project URL 和 Publishable key（旧版项目可用 anon key）。打开 config.js，填写两处：

window.KITCHEN_CONFIG = {
  supabaseUrl: 'https://你的项目编号.supabase.co',
  supabaseKey: '你的Publishable key或anon key'
};

这里只使用可公开的 key。不要使用以 sb_secret_ 开头的密钥、service_role key、数据库密码或登录密码。

5 · 上传到 GitHub Pages

  1. 登录 GitHub 新建仓库，名称例如 jianbao-kitchen。使用免费 Pages 时选择 Public。
  2. 选择 Add file → Upload files，上传这个文件夹里的文件，确保 index.html 直接位于仓库根目录，不要多套一层文件夹。上传 index.html、style.css、app.js、cloud.js、config.js、seed.json、部署教程.html，以及 .nojekyll（如上传界面不显示隐藏文件，可在仓库 Add file 中创建同名空文件）。README 与 setup.sql 可一并上传，它们不含账号秘密。
  3. 点击 Commit changes。
  4. 进入仓库 Settings → Pages → Build and deployment，Source 选择 Deploy from a branch，Branch 选 main，文件夹选 /(root)，点击 Save。
  5. 等待发布完成，打开 Pages 显示的网址，通常为 https://你的用户名.github.io/jianbao-kitchen/。

不用 Python、不用 Gunicorn、不用服务器端口。网站代码公开，但真实菜谱、食材和图片由 Supabase 登录及权限保护。不要上传个人备份 JSON、家人邮箱列表或密码。

6 · 登录并让家人试用

  1. 用步骤 3 创建的邮箱和密码登录。首次菜谱为空，点击“导入示例”，或直接添加自己的菜谱。
  2. 把 GitHub Pages 的网址发给家人，各自使用自己的家庭账号登录。
  3. 你添加一道带图片的菜，家人等待约 15 秒或点击“同步”，应该能看到。
  4. 家人同时编辑时会检测冲突；提示后先复制未保存的文字，关闭编辑框、点击同步，然后重新修改。
  5. 定期点击“备份”，将含图片的 JSON 下载到自己的电脑。

常见问题

  • 显示“还差最后一步”：config.js 仍为空。修改后重新上传，并按 Ctrl+F5 刷新。
  • 登录成功但无法读取家庭数据：确认执行了 setup.sql，并把该账号 UID 加入 family_members。
  • 上传失败：检查 Storage 中的 kitchen-images 桶和权限是否按脚本创建，以及免费空间是否已满。
  • 页面空白或组件未加载：检查浏览器能否访问 jsDelivr 与 Supabase；在家人实际使用的网络测试。
  • 长时间没用后连不上：到 Supabase 控制台检查项目是否暂停并恢复。
  • GitHub Pages 404：检查 index.html 是否在根目录，Pages 是否选 main 与 /(root)，等待部署完成。
  • 取消家人访问：管理员从 family_members 删除对应 UID；这不会删除共享菜谱。已被下载的资料无法远程收回。
